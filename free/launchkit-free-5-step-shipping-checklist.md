# LaunchKit Free — The 5-Step Shipping Checklist

The plain order of operations that takes a finished demo to a first paying user. Nothing motivational — just the sequence. Work the steps in order; do not skip ahead.

## 1. Deploy — get it live on a real URL
- Put the app on hosting you can link to (not localhost).
- Attach a custom domain or use the host's URL; turn on HTTPS.
- Click through the live site yourself: every button, the happy path and the error path.
- Done when a stranger can open the link and use it without you explaining.

## 2. Payments — accept real money before the launch post
- Connect a payment provider and create one product with one clear price.
- For one-time tools use a single price; for ongoing tools use a subscription.
- Run one real test transaction end to end, then refund it.
- Configure the post-payment redirect so the buyer lands somewhere that tells them what happens next.

## 3. 72-hour launch sequence — show up in this order
- Day 0: post in one builder community where your kind of user already is (one honest post: what it is, who it is for, link).
- Day 1: reply to every comment; fix the top complaint the same day.
- Day 2: post a short follow-up showing one real person using it; ask the first user for one sentence of feedback.
- Do not blast ten platforms at once — one place, done well.

## 4. Cold-start templates — talk to strangers, not just friends
- Keep three fill-in assets ready: a one-line pitch, a 3-line description, and a short demo screenshot.
- Put them where strangers see them: a community post, a directory listing, a comment on a related thread.
- Lead with the specific problem and the one audience; drop anything generic.

## 5. First-pay FAQ — answer the serious objection fast
- Write the answer to the three questions buyers actually ask: what exactly do I get, how is it delivered, can I get a refund.
- State the refund rule plainly and honour it without forms.
- When a hard question lands, answer it in public on the same thread — it answers the next ten buyers too.
